# Rail Types

**Status:** Draft  
**Last updated:** 2026-08-09  
**Owner:** TBD

## Purpose

Comparar materiales para servicio intensivo; validar con muestras.

| Material | Conductivity | Surface/oxidation | Cleaning | Cost/availability | Status |
|---|---|---|---|---|---|
| Brass | High candidate | Tarnishes; effect to measure | Routine required | PIKO Code 332 available | Verified product, performance TBD |
| Nickel silver | Lower than copper-rich brass; quantify by supplier | Oxide often considered less insulating; validate | Test | Supplier dependent | To Validate |
| Stainless steel | Lower conductivity | Corrosion resistant | May reduce polishing; validate | Supplier dependent | To Validate |
| Aluminum/other | Supplier-specific | Oxide/joining concerns | Test | Not baseline | To Validate |

Code 332 means nominal rail height 0.332 in; it does not define alloy or full profile alone.

## Test

Coupon resistance; 10 m voltage drop; contamination cycle; cleaning time; joint heating; wheel pickup stability; food-safe cleaning compatibility. Do not choose only by purchase price.
