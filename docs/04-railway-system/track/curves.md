## Purpose

Relacionar geometría con espacio, vehículo y líquidos.

PIKO publica R1 600 mm, R3 921.54 mm, R5 1243.08 mm y R7 1564.62 mm. Sus sets BR80 usan R1 y especifican radio mínimo 600 mm para ese producto.

Curvas cerradas aumentan ángulo de acople, resistencia, overhang y aceleración lateral. Vehículos largos pueden invadir el gálibo interior/exterior; líquidos responden a velocidad, transición y centro de gravedad.

## Candidate recommendation

Probar R1 como compatibilidad mínima de referencia, pero priorizar R3 o mayor en el diseño si layout y ensayos lo permiten. No adoptar radio final antes de W01 con carga.

| Test | Variables |
|---|---|
| CUR-001 | Empty, R1/R3/R5, low-to-target speed |
| CUR-002 | 1/3 kg, derailment/current/speed |
| CUR-003 | Filled cups, spill mass/video |
| CUR-004 | S-curve and turnout transition |
| CUR-005 | Overhang envelope |
