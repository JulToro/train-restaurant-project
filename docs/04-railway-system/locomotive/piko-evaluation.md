# PIKO G Evaluation

**Status:** Draft / Candidate supplier  
**Last updated:** 2026-08-09  
**Owner:** TBD

## Purpose

Evaluar PIKO como referencia, no seleccionarlo definitivamente.

## Verified

- PIKO lista sets G con locomotora, vagones, vía de latón, conexión y control.
- Set 37100: BR80, dos vagones, 12 curvas R1 600 mm, 22 V/36 VA, longitud publicada 750 mm y radio mínimo 600 mm.
- La página enlaza manual, dimensiones, lista de repuestos y drive completo 36102.
- PIKO vende vía Code 332 y declara compatibilidad con LGB/Aristo-Craft.
- Catálogo G incluye vía, rolling stock, accesorios y control digital.

## Advantages

BOM de referencia completo, repuestos visibles, drive reemplazable, varias geometrías y ecosistema amplio.

## Limitations / unknowns

No se publica tracción, carga remolcada, duty cycle comercial, IP rating, vida de engranajes ni soporte/importación en Colombia. “Weather resistant” no equivale a apto para restaurante o lavado.

## Candidate MVP-00

37100 es evaluable por disponibilidad publicada y vagones de carga; comparar contra un set simple LGB y costo puesto en Medellín antes de comprar.

## Questions

Garantía en uso comercial, stock regional, compatibilidad real de acoples/ruedas, temperatura admisible, lubricantes, partes críticas y lead time.
