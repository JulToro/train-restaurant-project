## Purpose

Definir qué medir antes de diseñar.

| Attribute | Candidate requirement | Status |
|---|---|---|
| Gauge | 45 mm | Candidate |
| Envelope/length/mass | Fit layout and barriers | TBD |
| Axles | Sufficient pickup/traction; count TBD | To Validate |
| Drawbar pull | Measured margin for train on worst curve/grade | TBD |
| Speed | Stable low-speed; upper limit from spill/throughput test | TBD |
| Duty cycle | Representative service endurance | TBD |
| Maintenance | Drive removable; consumables accessible | Candidate |
| Modularity | Commercial drive separated from body | Candidate |
| Body | Tool-light removable without disturbing drivetrain | Candidate |
| Control | Manual baseline, automation-ready interface | Candidate |
| Braking/stop | Predictable under load/loss scenarios | TBD |

3 kg normal and 5 kg overload apply to train payload hypotheses, not automatically to one locomotive rating.

## Verification

Dimensional inspection, drawbar test, curve/grade matrix, thermal/endurance, stop distance, maintenance drill and contamination test.
