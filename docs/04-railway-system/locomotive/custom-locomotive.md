# Custom Locomotive Evolution

**Status:** Draft  
**Last updated:** 2026-08-09  
**Owner:** TBD

## Purpose

Defer irreversible drivetrain engineering.

| Generation | Configuration | Gate |
|---|---|---|
| 0 | Commercial locomotive | Baseline and load evidence |
| 1 | Commercial motor block + custom body | Identity, removable body, no thermal regression |
| 2 | Commercial motor block + custom chassis/body | Interface control and maintainability |
| 3 | Commercial motor/gearbox + custom drivetrain | Only if block limits documented |
| 4 | OEM/custom system | Only if volume/economics/support justify |

## Design records per generation

BOM/version, drawings, mass/CG, interfaces, test results, failures, service hours, cost and rollback path.

## Candidate decision

Stop at the lowest generation that meets product and economic requirements. Custom is not inherently better; it transfers warranty, safety, spares and lifecycle responsibility to the project.

See: [motor blocks](motor-blocks.md), [traction tests](traction-tests.md), [risks](../../02-business-model/risks.md).
