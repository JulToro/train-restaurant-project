**Status:** Draft / professional food-safety review required  
**Last updated:** 2026-08-09  
**Owner:** TBD

## Purpose

Definir interfaces de alimento sin hacer afirmaciones regulatorias no verificadas.

| Need | Candidate feature | Test |
|---|---|---|
| Removal | Handles and keyed placement | Timed user test |
| Cup retention | Recess/holder adaptable to sizes | Curve/brake/spill |
| Secondary containment | Raised edge/removable liner | Measured spill |
| Cleaning | Smooth, accessible, dishwasher-compatible if approved | Cleaning validation |
| Insulation | Thermal barrier from vehicle | Temperature profile |
| Air exposure | Covers where menu requires | Sensory/temperature |
| Identification | Tray ID and clean/dirty status | Operations drill |

Food-contact material, detergent, temperature and reuse cycles require supplier documentation and Colombian professional/regulatory review. Mechanical retention must not trap fingers or make customers reach across live track.

## Menu co-design

Prefer stable containers and low free-surface liquids initially. Exclude open hot beverages until hazards and controls pass review. See: [safety requirements](../../03-product/requirements/safety.md).
