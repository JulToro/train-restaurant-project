# Wagon Requirements

**Status:** Draft / Candidate  
**Last updated:** 2026-08-09  
**Owner:** TBD

## Purpose

Definir vagón como equipo transportador limpio y estable.

| Attribute | Candidate requirement | Verification |
|---|---|---|
| Payload | 3 kg normal hypothesis; 5 kg overload test | Load matrix |
| Dimensions | Fit envelope, curves and table interface | CAD/mock-up |
| Tray | Removable without tools; positive location | User test |
| Cleaning | Food-contact assembly separated; inspectable | Cleaning validation |
| Stability | Low CG and retained load | Curve/brake test |
| Coupling | Versioned common interface | Gauge/force test |
| Wheels | Compatible with selected Code/profile/turnouts | Running test |
| Drain/containment | Spill cannot reach electrical/mechanical parts unchecked | Spill test |
| Identification | Unique ID and configuration version | Inspection |
| Maintenance | Wheel/bearing/tray access and cycle log | Drill |

No material is food-safe merely because it is printable or washable; approve food-contact components with qualified review.
