# Candidate Railway Standard

**Status:** Draft / Candidate Decision  
**Last updated:** 2026-08-09  
**Owner:** TBD

## Purpose

Crear una configuración inicial que debe sobrevivir pruebas.

| Attribute | Candidate | Evidence/status |
|---|---|---|
| Track gauge | 45 mm | Candidate; ecosystem compatibility |
| Ecosystem | G gauge commercial components | Candidate; “G” is not one exact scale |
| Rail | Code 332 brass baseline | PIKO verified; alternatives to test |
| Vehicle envelope | TBD from layout/barriers | To Validate |
| Coupling | Commercial G hook/loop baseline; interface TBD | Candidate |
| Minimum curve | Test R1 600, R3 921.54 and wider | No final decision |
| Maximum grade | TBD through traction tests | To Validate |
| Operating speed | Lowest stable range compatible with throughput | To Validate |
| Power | Track power baseline vs battery A/B | Candidate |
| Control | Manual first; block/sensor routing later | Candidate |
| Payload | 3 kg normal hypothesis; 5 kg overload experiment | Assumption |

## Change control

Toda aprobación debe registrar versión, evidencia, compatibilidad y efecto sobre [rolling stock](rolling-stock-standard.md). PIKO declara vía Code 332 de latón y compatibilidad con LGB/Aristo-Craft, pero el acople mecánico real debe probarse.
