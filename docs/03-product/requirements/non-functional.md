# Non-Functional Requirements

**Status:** Draft  
**Last updated:** 2026-08-09  
**Owner:** TBD

## Purpose

Definir cualidades medibles sin inventar umbrales.

| ID | Quality | Candidate requirement / measure |
|---|---|---|
| NFR-001 | Reliability | Entregas exitosas/100; target TBD tras baseline |
| NFR-002 | Availability | Uptime en ventana de servicio; target TBD |
| NFR-003 | Maintainability | MTTR, acceso sin desmontar vía, módulos reemplazables |
| NFR-004 | Performance | Tiempo de ciclo y órdenes/tren/hora |
| NFR-005 | Cleanability | Bandeja sin herramientas; superficies inspeccionables |
| NFR-006 | Modularity | Vía, drive, body, tray y control con interfaces versionadas |
| NFR-007 | Spares | Lista crítica y tiempo de reposición medido |
| NFR-008 | Scalability | Añadir bloque sin reescribir lógica central; validar MVP-04 |
| NFR-009 | Observability | V/I, estado, fallo, intervención y contador de ciclos |
| NFR-010 | Noise | Medir en mesa; límite según contexto/regla aplicable TBD |
| NFR-011 | Duty cycle | Endurance representativo antes de público |
| NFR-012 | Recoverability | Procedimiento seguro y tiempo de recuperación medido |
