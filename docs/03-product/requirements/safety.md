# Safety Requirements

**Status:** Draft — professional review required  
**Last updated:** 2026-08-09  
**Owner:** TBD

## Purpose

Crear requisitos candidatos; no reemplaza ingeniería de seguridad, inocuidad, seguros ni cumplimiento colombiano.

| ID | Hazard | Candidate requirement |
|---|---|---|
| SAF-001 | Spill | Contención secundaria y prueba de frenado/curva |
| SAF-002 | Hot liquid | Excluir del piloto público hasta análisis y control aprobados |
| SAF-003 | Pinch/entrapment | Guardas y separación de partes móviles |
| SAF-004 | Electricity | Fuente protegida, puesta a tierra cuando aplique y acceso restringido |
| SAF-005 | Short circuit | Protección y aislamiento por zona; evento registrado |
| SAF-006 | Derailment | Retención física donde una caída alcance personas |
| SAF-007 | Children | No acceso a vía/energía/desvíos; diseño probado |
| SAF-008 | Emergency | E-stop accesible que lleve movimiento a estado seguro |
| SAF-009 | Hygiene | Separar bandeja alimentaria del material rodante; protocolo validado |
| SAF-010 | Fire | Materiales/equipos revisados según norma aplicable |
| SAF-011 | Manual recovery | Bloqueo/desenergización antes de recuperar tren |
| SAF-012 | Restart | Rearme deliberado; no rearranque automático tras corte |
| SAF-013 | Allergen/cross-contact | Flujo de alimento bajo sistema del restaurante |
| SAF-014 | Incident | Registro, preservación y revisión de near misses |

## Gate

No operar con público hasta HAZID, revisión regulatoria/aseguradora, pruebas y entrenamiento. See: [risk register](../../02-business-model/risks.md).
