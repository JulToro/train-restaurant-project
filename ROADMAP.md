## Purpose

Mostrar el orden de aprendizaje. No se asignan fechas hasta contar con evidencia y capacidad.

| Stage | Goal | Exit evidence |
|---|---|---|
| Discovery | Validar problema, segmentos y precio | Hipótesis priorizadas y señal real de demanda |
| MVP-00 — Reference train | Obtener baseline comercial | Tracción, corriente, velocidad, temperatura y mantenimiento medidos |
| MVP-01 — Wagon | Crear un vagón compatible y limpiable | Circulación, acople y limpieza validados |
| MVP-02 — Load testing | Probar 1 kg, 3 kg y sobrecarga de 5 kg | Carga, curvas, frenado y endurance documentados |
| MVP-03 — Custom train | Integrar motor block y diseño propio | Sin degradar tracción, temperatura ni mantenimiento |
| MVP-04 — Automation | Automatizar ruta, desvío y detección | Operación segura, fallback y recuperación demostrados |
| MVP-05 — Pilot | Ejecutar cocina–mesa–retorno | Seguridad aprobada y métricas de cliente, operación y economía |
| Restaurant decision | Continuar, rediseñar o detener | Evidencia consolidada, no entusiasmo aislado |

## Working rule

Cada etapa produce un experimento, un reporte y una decisión. Si falla un criterio crítico de seguridad, demanda o economía, se corrige o detiene antes de invertir en la siguiente.
